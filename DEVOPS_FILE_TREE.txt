CI/CD Pipelines Overview
========================

1. Node.js SDK Pipeline (nodejs-ci.yml)
   ├── Lint & Format Check
   ├── Test (Node 16, 18, 20)
   ├── Build & Validate
   ├── Security Scan
   └── Publish to npm & GitHub Packages

2. Python SDK Pipeline (python-ci.yml)
   ├── Lint & Format Check
   ├── Test (Python 3.8, 3.9, 3.10, 3.11)
   ├── Build & Validate
   ├── Security Scan
   └── Publish to PyPI & Test PyPI

3. Java SDK Pipeline (java-ci.yml)
   ├── Lint & Format Check
   ├── Test (Java 11, 17, 21)
   ├── Build & SonarCloud Analysis
   ├── Security Scan
   └── Publish to Maven Central & GitHub Packages

4. .NET SDK Pipeline (dotnet-ci.yml)
   ├── Lint & Format Check
   ├── Test (.NET 6.0, 7.0, 8.0)
   ├── Build & Package
   ├── Security Scan
   └── Publish to NuGet & GitHub Packages

5. Integration Tests Pipeline (integration-tests.yml)
   ├── Setup Mock HCX Server
   ├── Test All SDKs
   ├── Cross-SDK Compatibility Tests
   ├── Performance Tests
   └── Notify Results

6. Release Management (release.yml)
   ├── Prepare Release
   ├── Release Each SDK
   ├── Create GitHub Release
   └── Send Notifications

Makefile Commands
=================

Installation:
  make install           # Install all SDK dependencies
  make install-nodejs    # Install Node.js dependencies
  make install-python    # Install Python dependencies
  make install-java      # Install Java dependencies
  make install-dotnet    # Install .NET dependencies

Building:
  make build             # Build all SDKs
  make build-nodejs      # Build Node.js SDK
  make build-python      # Build Python SDK
  make build-java        # Build Java SDK
  make build-dotnet      # Build .NET SDK

Testing:
  make test              # Run all tests
  make test-nodejs       # Test Node.js SDK
  make test-python       # Test Python SDK
  make test-java         # Test Java SDK
  make test-dotnet       # Test .NET SDK
  make test-integration  # Run integration tests
  make test-coverage     # Generate coverage reports

Code Quality:
  make lint              # Run all linters
  make format            # Format all code
  make security          # Run security scans
  make ci-check          # Run all CI checks locally

Docker:
  make docker-up         # Start Docker services
  make docker-down       # Stop Docker services
  make docker-logs       # View Docker logs
  make docker-clean      # Clean Docker resources

Utilities:
  make clean             # Clean all build artifacts
  make version-check     # Check tool versions
  make setup-dev         # Complete dev environment setup
  make help              # Display all commands
